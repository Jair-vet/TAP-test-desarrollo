# Frontend — Angular 19 (TypeScript 5.8)

SPA con Tailwind CSS v4, Angular CDK y signals. Ver [`../README.md`](../README.md) y
[`../docs/GUIA-DEL-CODIGO.md`](../docs/GUIA-DEL-CODIGO.md).

```bash
npm ci
npm start          # ng serve con proxy a http://localhost:8080 (stack Docker levantado)
npm run lint       # angular-eslint
npm run test:ci    # Karma + Jasmine (Chrome headless)
npm run build      # build de producción
```
